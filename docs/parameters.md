# Parameters

Every number the model is set with: in each region's settings and among the model's own constants. Generated by `tools/params_doc.py` from the files themselves, so it lists what runs. The note is the file's own comment beside or above the number, where its source is given; `ref:` keys link to [references.md](references.md). When a number was set, and why it changed, is in the file's history (click its line, then *History*). Places, names and station codes are left out. Do not edit by hand.
